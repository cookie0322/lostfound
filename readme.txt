================================================

      不要一次读完再动手。

------------------------------------------------

五、读完应该能回答这五个问题
------------------------------------------------
1. 系统有几个模块？分别叫什么、依赖谁？
2. 数据库有哪几张表？主键与唯一约束是什么？
3. 认领状态有几个？从哪到哪要经过哪些事件？
4. 认证走什么流程？拿不到 SSO 怎么办？
5. 哪些事明确不做？（信息发布、匿名聊天、智能匹配、高价值物品）

六、建议的阅读顺序（配合动手）
------------------------------------------------
第 1 步：读 一、二            → 搭项目骨架、写建表 SQL
第 2 步：读 图 附 2-1 / 2-2   → 写状态机与转移表
第 3 步：读 图 附 2-3 / 2-4、实体类图 → 写 Controller / Service / 实体
第 4 步：回头对 二、三 的约束与裁决 → 检查代码有没有走样

七、几条硬约束（写代码时贴在旁边）
------------------------------------------------
· 技术栈：Java 17 + Spring Boot 3 + MyBatis-Plus + MySQL 8；Vue 3 + Element Plus
· 部署：一台个人 PC 本地运行，前后端与数据库同机，无独立服务器
· 模块数 ≤ 6，代码总量 ≤ 1 万行
· 零预算：不引入商业 OCR、人脸识别、大模型 API、付费短信；不使用 Redis 与消息队列
· 不采集手机号等联系方式；不保存密码（登录由学校统一身份认证完成）
· 只受理低价值日常物品；证件、电子产品、现金与贵重饰品不受理
· 认领只有单向：拾得者发招领，失主来认领

## 读完应该能回答这五个问题

1. 系统有几个模块？分别叫什么、依赖谁？
2. 数据库有哪几张表？主键、唯一约束是什么？
3. 认领状态有几个？从哪到哪要经过哪些事件？
4. 认证走什么流程？拿不到 SSO 怎么办？
5. 哪些事**明确不做**？（发布、聊天、匹配、高价值物品）

如果这五个问题答不上来，就还没读够。

## 一条建议

**不要一次读完再动手。** 推荐顺序：

> 先读 1、2、3 → 建项目骨架和表结构 → 读 8、9 → 写状态机 → 读 10、11 → 写接口和实体 → 最后读 5、6、7 检查分包有没有走样

这样每一步都有具体产出，不会读完了还不知道从哪下手。
